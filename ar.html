🔗 주요 통신 흐름 & 플랫폼 차이
🌐 Web → Spring Boot
HTTP + JWT
Refresh Token: HTTP-only Cookie (자동 관리)
결제: iframe (브라우저 내장)
SSE 수신: EventSource API
📱 App → Spring Boot
HTTP + JWT Bearer Header
Refresh Token: Expo SecureStore (iOS Keychain / Android Keystore)
결제: WebView + URL 인터셉트
SSE 수신: EventSource + AppState fallback
🔒 Spring Boot → Raspberry Pi
HTTP + Device JWT (role: DEVICE)
JWT_SECRET 공유 (Spring Boot 서명 → Pi 검증)
CORS: Spring Boot 주소만 허용
Pi → Spring Boot: 센서 데이터 DB 저장
💾 Spring Boot → Data Layer
AWS RDS: MyBatis (SELECT FOR UPDATE 재고 비관적 락)
AWS S3: Presigned URL 방식 이미지 업로드
SSE: 알림 발생 시 Web · App 동시 스트리밍
📋 Web vs App 핵심 차이
구분 🌐 Web (React) 📱 App (React Native)
토큰 저장 HTTP-only Cookie (브라우저 자동 관리) Expo SecureStore (OS 수준 암호화)
API 전송 withCredentials (쿠키 자동 첨부) Authorization: Bearer 헤더
결제창 iframe (브라우저 내장) WebView + URL 인터셉트
SSE 처리 EventSource API EventSource + AppState fallback
AI 기능 Gemini API 연동 (레시피·리뷰 분석) 미적용
